# Taller Oscar Rizzi

Presentación interactiva de la propuesta de gestión: clientes, presupuestos, mensajes de WhatsApp y seguimiento de aseguradoras.

## Ver la presentación

[Abri la presentación](https://nazarenomalpassi.github.io/taller-oscar-rizzi/)

También podés descargar `index.html` y abrirlo con un navegador. Funciona sin conexión.

- Usá las flechas para recorrer las secciones.
- En la sección Envíos por WhatsApp podés probar los mensajes y su configuración.
- La presentación contiene una demostración con datos de clientes e importes ilustrativos; no realiza envíos reales.
- `ejemplo_presupuesto_emitido.pdf` contiene el ejemplo del documento de reparación.
